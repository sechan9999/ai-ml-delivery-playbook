## What's inside

A single-page reference covering:

- **First principles** — the model is the small part; a confident wrong answer is the enemy.
- **Reference architecture** — separating invariants (feature consistency, registry, evaluation, observability) from substrate (warehouse-native / cloud / on-prem).
- **Delivery lifecycle** — a gate at every stage from Frame to Govern.
- **Evaluation ladder** — offline → shadow → canary, with GenAI/RAG metrics (grounding, hallucination, abstention).
- **Decision frameworks** — classical vs LLM, build vs buy, substrate choice, RAG design.
- **Responsible AI & model risk** — SR 11-7, NIST AI RMF, EU AI Act, mapped to practice.
- **Human-in-the-loop patterns** — review, escalation, override, feedback.
- **Observability & operations** — data drift, concept drift, operational telemetry.
- **Anti-patterns** — the failure modes designed against.
- **Pre-flight checklists** — before modeling, before deploy, before handoff.

## About

This playbook reflects how I build and reason about AI systems. The patterns are
grounded in systems I have shipped — a closed-loop agent operations platform, a
metadata-governed AI guardrail layer, a fully on-prem LLM agent, and regulated
statistical modeling for public health. It is a living document.
